This QAT toolkit / repository contains three parts:

A. This Readme file, containing the test case for an AI-generated web application;
B. The AI prompt used to create the test web application named "webapp-generation-prompt.txt"; and
C. The single-file PHP web application generated by AI.

1. Test Case ID: TC-DataEntry-001
2. Test Case Title: Data Entry - Valid
3. Test Case Description: Functional Testing of Data Entry page with Backend validation using MySQL queries.
4. Preconditions: Kara David Birthday Wishnote App is installed locally and MySQL database is pre-populated for comparison. Data entry page is accessed in latest Chrome/Firefox browser.
5. Test Data: Five (5) valid entries containing First Name, Last Name, Government Position, and Location and within their maximum character limits.
6. Test Steps:
   a. Verify that the form contains labels in proper order and the text boxes are writable
   b. Verify the "Send Wish Note" button.
   c. Enter test data on their respective fields
   d. On clicking of "Send Wish Note" button, a modal will appear.
   e. Verify if the modal contains the same entry as your test data
   f. Click the Cancel button
   g. Click again on "Send Wish Note" button, and click on "Confirm and Send" button in the modal box.
   h. Verify if a successful entry message shows in the Data Entry page.
   i. Verify the test data if it shows in the database.
7. Expected Results:
   a. The form contains labels in this order: "Target's First Name", "Target's Last Name", "Target's Government Position", and "Target's Location"; all text boxes are writable
   b. The "Send Wish Note" button changes color on hover and is not disabled
   c. The respective fields accept data entries of valid test data.
   d. A "Verify Target Data" modal appears centered over the page.
   e. The modal shows the same First Name, Last Name, Government Position and Location as entered.
   f. The modal closes and the form keeps the entered data.
   g. The modal opens again; clicking "Confirm & Send" submits the form.
   h. The message "Success! The wish note has been sent." appears above the form.
   i. All five entries appear in main_corrupt_politicians with FirstName, LastName, GovPosition and Location matching the test data.
8. Actual Results:
   a. The form contains labels in this order: "Target's First Name", "Target's Last Name", "Target's Government Position", and "Target's Location"; all text boxes are writable
   b. The "Send Wish Note" button changes color on hover and is not disabled
   c. The respective fields accept data entries of valid test data.
   d. A "Verify Target Data" modal appeared centered over the page.
   e. The modal showed the same First Name, Last Name, Government Position and Location as entered.
   f. The modal closed and the form kept the entered data.
   g. The modal opened again; clicking "Confirm & Send" submitted the form.
   h. The message "Success! The wish note has been sent." appeared above the form.
   i. Query used: SELECT * FROM main_corrupt_politicians;
      Result: FirstName, LastName and GovPosition were saved for all five entries, but the Location column was empty/NULL. (Confirm this against your own MySQL output.)
9. Status: Failed (Location was not saved to the database)
